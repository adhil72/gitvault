# GitVault CLI reference

> Generated by `pnpm gen:docs` from the command definitions. Do not edit by hand.

## `gitvault`

GitVault: encrypted secrets stored in your own private GitHub repository

- `--json`: Print machine-readable JSON on stdout (human text goes to stderr)
- `--vault`: Vault id to use (default: the vault chosen with `gitvault vault use`)
- `--non-interactive`: Never prompt; fail with an error instead

### `gitvault version`

Show version information

### `gitvault auth`

Sign in to GitHub

#### `gitvault auth login`

Sign in. Without flags, uses the GitHub device flow

- `--with-token`: Read a personal access token from stdin
- `--from-gh`: Reuse the token of the GitHub CLI (`gh auth token`)
- `--gh-user`: Sign in as this account of the GitHub CLI (see `gitvault auth accounts`)

#### `gitvault auth logout`

Forget the GitHub token

#### `gitvault auth status`

Show the signed-in account

#### `gitvault auth accounts`

List the accounts of the GitHub CLI (`gh`)

### `gitvault vault`

List, create and manage vaults

#### `gitvault vault list`

List the vaults on this device (add --remote to also look on GitHub)

- `--remote`

#### `gitvault vault create`

Create a vault (and a private GitHub repository when signed in)

- `--name` (required)
- `--description`
- `--repo-name`: GitHub repository name (default: gitvault-<name>)
- `--local-only`: Do not create a GitHub repository
- `--password-stdin`: Read the master password from stdin instead of prompting

#### `gitvault vault use`

Choose the default vault

- `<id>` (required)

#### `gitvault vault info`

Show one vault

#### `gitvault vault connect`

Clone a vault found on GitHub (owner/name)

- `<repo>` (required)

#### `gitvault vault forget`

Remove the local copy (GitHub is untouched)

- `<id>` (required)

#### `gitvault vault password`

Change the master password

- `--password-stdin`: Read the master password from stdin instead of prompting

#### `gitvault vault recovery`

Create a new recovery key

- `--password-stdin`: Read the master password from stdin instead of prompting

### `gitvault unlock`

Unlock a vault (prints a session token with --export)

- `--password-stdin`: Read the master password from stdin instead of prompting
- `--recovery-key-stdin`: Unlock with a recovery key read from stdin
- `--export`: Print the session token (`GITVAULT_SESSION`) for scripts

### `gitvault lock`

Lock a vault and wipe its key

### `gitvault trust`

Trust folders: this device unlocks by itself only inside them (and their subfolders)

#### `gitvault trust add`

Trust a folder and everything under it (trusts this device first if needed)

- `<path>`: The folder (default: the current one)
- `--env`: Only for these environments, e.g. --env development. Default: all of them
- `--password-stdin`: Read the master password from stdin instead of prompting

#### `gitvault trust list`

List the trusted folders

#### `gitvault trust remove`

Stop trusting a folder

- `<path>` (required)

### `gitvault device`

Trust devices so they unlock without the master password

#### `gitvault device trust`

Trust this device (or, with --export, print a key for a server or CI job)

- `--name` (required): A name to recognise the device by, e.g. laptop or prod-server
- `--export`: Print a device key for another machine (shown once) instead of trusting this one
- `--password-stdin`: Read the master password from stdin instead of prompting

#### `gitvault device list`

List the trusted devices of the vault

#### `gitvault device revoke`

Stop trusting a device (needs the vault unlocked)

- `<id>` (required)
- `--password-stdin`: Read the master password from stdin instead of prompting

### `gitvault secret`

Add, read, change and delete secrets

#### `gitvault secret add`

Add a secret. The value comes from stdin, a file, or a hidden prompt

- `<name>` (required)
- `--kind`
- `--environment`
- `--tag`
- `--notes`
- `--expires`: Expiry date, YYYY-MM-DD
- `--remind-days`
- `--value-stdin`: Read the value from stdin
- `--from-file`: Read the value from a file

#### `gitvault secret get`

Show a secret (value masked unless --reveal / --raw)

- `<secret>` (required)
- `--reveal`: Include the plaintext value (recorded in the audit log)
- `--raw`: Print only the value (implies --reveal)
- `--environment`: Disambiguate when the name exists in several environments

#### `gitvault secret list`

List secrets

- `--search`
- `--environment`
- `--tag`
- `--kind`
- `--favorites`
- `--expiring-days`
- `--sort`

#### `gitvault secret update`

Change fields of a secret

- `<secret>` (required)
- `--name`
- `--kind`
- `--environment`: Empty string clears it
- `--tag`: Replaces all tags (repeat the flag)
- `--notes`
- `--expires`: YYYY-MM-DD, or empty to clear
- `--favorite`
- `--value-stdin`: Read the value from stdin
- `--from-file`: Read the value from a file

#### `gitvault secret rotate`

Set a new value

- `<secret>` (required)
- `--value-stdin`: Read the value from stdin
- `--from-file`: Read the value from a file

#### `gitvault secret delete`

Delete a secret (restorable from history)

- `<secret>` (required)

#### `gitvault secret history`

Show the version history

- `<secret>` (required)

#### `gitvault secret restore`

Restore an old version

- `<secret>` (required)
- `<commit>` (required)

#### `gitvault secret search`

Search names, environments and tags

- `<text>` (required)

### `gitvault env`

List environments with secret counts

#### `gitvault env list`

List environments with secret counts

#### `gitvault env export`

Print one environment's variables as JSON (for app loaders such as the Node package)

- `<environment>` (required): Environment name, e.g. development or production

### `gitvault tag`

List tags with secret counts

#### `gitvault tag list`

### `gitvault import`

Import secrets from a .env file

#### `gitvault import env`

Import a .env file

- `<file>` (required)
- `--environment`
- `--overwrite`: Replace values of secrets that already exist
- `--preview`: Show what would happen without changing anything

### `gitvault export`

Export secrets as a .env file

#### `gitvault export env`

Print (or write) a .env file

- `--environment`
- `--tag`
- `--output`: Write to a file (mode 0600) instead of stdout

### `gitvault generate`

Generate passwords, passphrases and PINs

#### `gitvault generate password`

- `--length`
- `--no-uppercase`
- `--no-lowercase`
- `--no-digits`
- `--no-symbols`
- `--avoid-ambiguous`

#### `gitvault generate passphrase`

- `--words`
- `--separator`
- `--capitalize`

#### `gitvault generate pin`

- `--length`

### `gitvault run`

Run a command with secrets injected as environment variables (values are never printed)

- `--environment`
- `--tag`
- `--redact`: Capture output and replace secret values with [REDACTED]
- `<command>` (required): The command to run (after `--`)

### `gitvault inject`

Fill a template with secret values

- `--in` (required): Template with `{{ NAME }}` or `{{ gitvault://NAME }}` placeholders
- `--out` (required): Output file (mode 0600)
- `--environment`
- `--tag`

#### `gitvault sync conflicts`

#### `gitvault sync resolve`
