# Changes from upstream shadcn/ui

These files are generated by `pnpm dlx shadcn@latest add <component>` and then owned by us.
Record every deliberate deviation here so upgrades (`add <component> --overwrite`) can re-apply them.

| File                       | Change                                                                                                                                                                            | Why                                                                   |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| all                        | `import { cn } from "cn"` -> `from "@/lib/utils"`                                                                                                                                 | The CLI emitted a bare `cn` alias that does not resolve in this repo. |
| `button.tsx`               | Added `danger` variant (outlined red). `font-semibold`. Sizes: `sm` 32px, `default` 40px, `lg` 44px. `link` uses the `info` token.                                                | Matches the Figma Components page (GitHub style).                     |
| `../../styles/globals.css` | Theme variables replaced with the GitHub Dark/Light tokens; extra tokens `inset`, `subtle`, `success`, `warning`, `info`, `done`, `brand-line`; radius 6px; JetBrains Mono added. | Figma variable collection "GitHub Theme".                             |
